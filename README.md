# BOON D' BOT

BOON D' BOT is an emergency assistance chatbot designed to help people find guidance and relevant resources during difficult situations.

## What it aims to do

- Provide guidance for emergency situations.
- Help users find relevant emergency services and local resources.
- Support location-aware assistance.
- Offer clear first-aid information.
- Help users prepare for hazards and unexpected situations.
- Work toward essential offline support.
- Support multiple Indian languages and be easy to use for people of different ages.

## Project

The application is being developed as a web application, with Android support and real-world deployment as future goals.

## Run locally

Make sure Python is installed, then run these commands from the project folder:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Important

This project is under development. Current emergency responses and sample resources may be incomplete or illustrative. The application does not contact emergency services unless a real integration is explicitly implemented and verified. Do not rely on this project as an emergency service.

## Contributing to development

The project is being built incrementally, with an emphasis on clear code, simple design, accessibility, reliability, and India-specific needs.
